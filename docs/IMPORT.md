# 账本导入

直接把 `.csv` 或 `.xlsx` 文件发给机器人即可自动导入（QQ 或 Telegram 均可）。

## 支持的列（表头自动识别，中文/英文均可）

| 列 | 可识别表头 |
|---|---|
| 日期 | 日期 / 时间 / 消费日期 / date / time |
| 金额 | 金额 / 消费金额 / 支出金额 / amount / price |
| 分类（可选） | 分类 / 类别 / category |
| 备注（可选） | 备注 / 描述 / 说明 / 明细 / description |

金额按「元」填写（如 `86.5`），系统自动转分为整数存储。负金额（收入）会跳过并提示。

## 示例 CSV

```csv
日期,金额,分类,备注
2026-08-01,86.5,餐饮,吃火锅
2026-08-02,23,交通,打车回家
2026-08-03,35,购物,日用品
```

## 支持格式

- CSV：UTF-8 / UTF-8 BOM / GBK 自动识别。
- Excel：`.xlsx` / `.xls`（取第一个工作表）。
- 表头不必在第一行（会自动在文件前 10 行内查找）。

## 导入模板

管理界面「状态与备份」页可下载官方导入模板（CSV）。
