本地模型（Ollama，独立容器）
启用

停用只停止调用、保留模型；「删除本地模型」才会真正移除文件（需重新下载）。

首次使用（3 步）：
① 在服务器启动 Ollama 容器：cd /opt/paas && docker compose --profile ai up -d
② 点下方「查看状态」，显示“Ollama 在线”后继续
③ 点「拉取模型」，首次约 400MB，请等待提示“已安装完成”

从下拉选一个即可；想用更大模型可手填其他 Ollama 模型名（如 qwen2.5:7b），填什么就拉取什么。

默认 http://localhost:11434 即可，这是 PAAS 调用 Ollama 的地址（不是下载地址）。只有当 Ollama 装在别的机器或改了端口时才需要改成对应地址，如 http://192.168.x.x:11434。
